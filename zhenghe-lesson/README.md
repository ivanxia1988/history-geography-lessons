# 第二课：郑和下西洋

主问题：大船为什么也要等风？适合初中生亲子共读约15—20分钟。

按照工作区 `AGENTS.md`：仅二维地图、普通地图／卫星实景图切换、地点讲解、上一地点／下一地点与讨论提示。无3D、飞行、巡游、自动镜头或额外功能。第一课保持原样。

七个讲解地点：长乐、占城、满剌加、锡兰、古里、忽鲁谟斯、麻林（东非代表）。地图综合不同航次、支队的部分代表地点，编号是讲解顺序，线条不表示某一次航行的完整轨迹。页面包含故事、地理关键点、趣味点、讨论提示、看图任务及资料链接。

文件：`dist/index.html`、`dist/style.css`、`dist/app.js`、`dist/vendor/`（Leaflet 1.9.4、Natural Earth 备用海陆轮廓）。普通底图为 OpenStreetMap，卫星影像为 Esri World Imagery；需要网络，没有账号或定位数据采集。

本地：`python3 -m http.server 8766 --bind 127.0.0.1 --directory dist`。
检查：`node --check dist/app.js`；实际浏览器核对底图切换、点位与讲解联动、前后按钮边界、手机布局。Sites 公开访问，无需登录或密码。
